# Обслуживание карты проекта

В этой папке лежит всё, что отвечает за актуальность файла [`FILES.md`](../FILES.md)
(полная карта ключевых файлов и папок с комментариями) и блока «Ключевые файлы
и папки» в корневом [`README.md`](../README.md).

## Состав

| Файл | Назначение |
|---|---|
| [`file_map_registry.md`](file_map_registry.md) | Реестр путей и текстовых комментариев. **Единственный файл, который нужно править вручную.** |
| [`update_file_map.py`](update_file_map.py) | Генератор: читает реестр, обходит дерево репозитория, считает размеры и даты, пишет `FILES.md` и блок в `README.md`. Зависимостей нет — только стандартная библиотека Python. |
| `README.md` | Этот файл. |

## Как пользоваться

Все команды выполняются из **корня репозитория**.

```bash
# Полное обновление карты (FILES.md + README.md)
python tools/update_file_map.py

# Только проверить, не устарела ли карта (ничего не записывает).
# Возвращает код 0, если актуальна, и 1, если пора обновлять.
python tools/update_file_map.py --check
```

### Плановый интервал

Карта должна обновляться **раз в 3 дня** (константа `CADENCE_DAYS` в скрипте).
Дата следующего планового обновления печатается в сводке и записывается в шапку
`FILES.md` — при запуске после наступления этой даты скрипт напомнит об этом.

Проще всего поставить напоминание и раз в три дня выполнять одну команду:

```bash
python tools/update_file_map.py && git add FILES.md README.md && git commit -m "docs: обновить карту проекта"
```

Автоматизация (GitHub Actions с cron или планировщик Windows) намеренно не
подключена: карта пересчитывается только когда вы сами этого хотите.

## Как добавить новый файл или папку в карту

1. Откройте [`file_map_registry.md`](file_map_registry.md).
2. Добавьте строку в нужный раздел в формате:
   ```
   - путь/к/файлу :: Что это и зачем нужно.
   ```
3. Запустите `python tools/update_file_map.py`.

Если путь существует в дереве, но не описан, он автоматически появится в разделе
«Не описано в реестре» файла `FILES.md` — по нему удобно находить пробелы в карте.

## Формат реестра

- `## Название` — заголовок раздела карты.
- `- <путь> :: <комментарий>` — запись. Путь относительно корня, разделитель `/`.
- Путь с `/` на конце — папка (показывается число файлов и объём).
- Символы `*` и `?` — маска (например `*/README.md`).
- Префикс `!` у папки — «непрозрачная»: содержимое считается описанным и не
  попадает в «Не описано» (нужно для генерируемых каталогов вроде `chapter_files/`).
